# 💈 Valmir Barber

Website desenvolvido para a barbearia **Valmir Barber**, localizada em Fortaleza.
O projeto tem como objetivo apresentar os serviços, estrutura, avaliações de clientes e facilitar o contato para agendamentos.

## 💈 Funcionalidades

* 📱 Menu mobile interativo
* 🎯 Scroll suave entre seções
* 🔥 Destaque automático do menu ao rolar a página
* ✂️ Exibição de serviços com preços e descrição
* 📹 Seção com vídeos do espaço da barbearia
* ⭐ Área de avaliações de clientes
* 📍 Mapa integrado com localização real
* 📞 Botão flutuante do WhatsApp para contato rápido
* 📩 Formulário de contato com validação em JavaScript
* ⏰ Exibição de horários de funcionamento
* 🎨 Animações ao rolar a página
